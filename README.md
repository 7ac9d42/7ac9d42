### How I Build

认同并尽可能接近以下准则：

- **保持简单 (KISS & YAGNI)**：清晰、直观且易维护优先，拒绝过度抽象与模式堆砌
- **最小必要与精准定位**：以解决实际问题为唯一导向，改动克制，减少冗余重构与非必要依赖
- **闭环与确定性**：追求逻辑自洽，低耦合高内聚，保持代码与运行环境的整洁
